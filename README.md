# Repositório Java

Bem-vindo ao meu repositório de **Java**! 

Este espaço é dedicado ao meu aprendizado e desenvolvimento na linguagem Java, reunindo exercícios, estudos, projetos e práticas de programação.

O objetivo é registrar minha evolução como desenvolvedor, explorar conceitos da linguagem e desenvolver minhas habilidades em programação orientada a objetos.

## Tecnologias utilizadas

- **Java** – Linguagem principal.
- **Visual Studio Code** – Ambiente de desenvolvimento.
- **Git e GitHub** – Controle de versão e armazenamento dos projetos.

## Conteúdos estudados

- Lógica de programação;
- Variáveis e tipos de dados;
- Operadores aritméticos e lógicos;
- Estruturas condicionais (`if`, `else`, `switch`);
- Estruturas de repetição (`for`, `while`, `do while`);
- Arrays e matrizes;
- Métodos e funções;
- Programação Orientada a Objetos (POO);
- Classes e objetos;
- Encapsulamento;
- Herança e polimorfismo;
- Tratamento de exceções.
